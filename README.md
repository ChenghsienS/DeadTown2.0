# Dead Town V1.1.7 — 房间通讯、角色外观与救援

新增浏览器多人合作：你的电脑运行服务器，朋友访问同一个网址，在大厅创建或加入独立房间。原单人游戏、像素美术、作者头像和 CEDRRRIIICCC 署名保留。版本按每个数字 0–14、逢 15 进位递增。

## 启动

- **单人：**完整解压，用 Chrome / Edge 打开 `index.html`。
- **多人开服：**安装 Node.js 22 或更新版本，双击 `Start-Server.bat`，在浏览器打开 `http://localhost:8080` → 多人合作。依赖已随包内置，无须安装 npm 包。
- **邀请异地朋友：**先安装官方 cloudflared，再运行 `Start-Tunnel.bat`，分享生成的网址。详细步骤、房间规则和故障排查见 **[MULTIPLAYER-README.md](MULTIPLAYER-README.md)**。

## V1.1.3：排行榜连接与成绩补传（历史记录）

- **连接与提示：**排行榜请求最长等待 8 秒；超时、网络不通、服务不可用、权限问题和缺少数据表分别提示。刷新与菜单同时发起的榜单请求合并，避免卡在加载状态或重复请求。
- **成绩补传：**结算时按当局玩家名字保存待上传最高分。上传失败保留队列；联网事件、手动刷新以及停留菜单时每 30 秒尝试补传。关掉游戏后，仍可在同一浏览器、同一启动位置重新打开后继续上传。默认名字 Player 沿用不参榜规则。
- **确认与并发：**服务器确认保存后才移除队列。查询后有更高分写入时，本客户端的较低分不会覆盖它；新名字插入冲突时重新检查。改名期间进行的上传仍归属于原名字，旧名字的异步查询不会污染新名字的个人纪录。
- **缓存：**连接失败时可以显示上次下载的榜单，并明确标注尚未刷新；不会把本地分数冒充已上传的全球成绩。存储不可用时提示保持页面打开，待上传成绩继续留在内存。
- **线上状态：**本次访问原项目的榜单和健康接口均收到 503 连接失败；当前环境也未解析出项目域名，尚不能判断是项目停用还是环境网络问题。未修改远端数据，也没有向真实榜单写入测试成绩。需要连接原 Supabase 项目，检查项目状态、数据表和读写权限后才能完成线上恢复。

客户端已通过 27 个排行榜场景及菜单入口检查。验证记录和后续检查项见 `verification/LEADERBOARD-V1.1.3.md`。此前燃烧自爆、掉落吸附、小地图和其他战斗逻辑保持原样。

## V1.1.0：多方向焦尸与燃烧自爆（历史记录）

- **六个倒地方向：**普通、奔跑、爬行、跳扑和冲锋丧尸被火焰烧死时，可向左、右、左上、右上、左下或右下倒下。倒地方向独立于活着时的朝向，每个丧尸死亡时确定一次，动画过程中保持稳定；身体完整转动、滑落并落地，阴影与灰烬跟随倒地方向。爬行丧尸继续采用贴地失力滑落，避免竖起来。Boss 沿用现有倒地动画。
- **自爆丧尸直接爆炸：**移除其焦尸及倒地动画。火焰直接命中或持续烧伤致死后，先触发原有自爆，再立即在原位置生成一个燃烧瓶火区；非火焰击杀仍只爆炸。
- **与燃烧瓶共用效果：**火区直接复用燃烧瓶的创建、火焰、烟雾、照明和伤害流程，半径 96、持续 6 秒。附近丧尸、Boss 和玩家都会受到对应的接触／持续燃烧伤害，墙体继续遮挡火区伤害。火焰离身后的 3 秒余烧和玩家自伤规则保持原样。
- **连锁规则：**火区可以烧死下一只自爆丧尸并留下新的火区。只按最终致死伤害判断：已经着火但最后被子弹、电弧或爆炸杀死，不会额外留下火区。每只被烧死的自爆丧尸只创建一个火区；原有爆炸连锁仍可发生，击杀和分数只结算一次。
- **美术工作台：**焦尸目录覆盖五类丧尸、六个倒地方向、四种身体朝向和三种外观，共 360 组／10440 帧；新增燃烧自爆火区预览，移除自爆丧尸焦尸条目。保留其他类型原有主方向资源 ID 和旧草稿导入能力。基础目录现为 1314 组／25015 帧，当前地图资源另行加入。

- **Horde 压力测试：**开发者面板展开「Horde 尸潮压力测试」，输入 25–1000 的数量并生成。每帧最多加入 20 只，最多同时存在 2000 只测试丧尸。按距离分区随机选择与玩家连通、无障碍、没有重叠的出生点，混合六种非 Boss 丧尸；出生时再次检查玩家和其他丧尸位置。面板显示存活测试数、全部丧尸数、排队数与本批实际生成数；空间不足或出生点被移动中的实体占据时，以实际数为准。清除仅移除测试丧尸和待生成队列，不触发击杀、掉落或自爆。可直接观察右上角 FPS／1% LOW；暂停和美术工作台期间不生成。

## 继承 V1.0.8：死亡肢解的帧率边界修复

上一版修复了尸体数量上限提前清理新动画的问题，但遗漏了与帧率有关的落地判定。这次在 40／50 Hz 等时间步下复现了丧尸死亡后原地冻结、肢体不飞散的问题。

- **帧率边界修复：**死亡短暂停顿恰好结束于 0.1 秒时，旧代码会运行一个长度为 0 的物理步骤；此时肢体高度为 0、速度仍朝上，却被标记为已落地。现在停顿结束后按固定的 1/120 秒物理步长更新，只有正在下降且接触地面的肢体才会落地，0 时间步不会推进或冻结动画。
- **真实运动验证：**检查肢体在连续帧中的位置、旋转和实际绘制像素；不同帧率下，相同动画时刻得到相同画面。落地后停止运动，超额残骸完成动画后再淡出。
- **自爆连锁修复：**手雷、火箭和燃烧区域按本次命中的目标列表结算，避免自爆连锁删除数组元素后，同一存活目标又被同一次伤害重复命中。
- **特殊死亡效果：**Boss 保留完整倒地，自爆丧尸保留爆炸，普通丧尸继续肢解；原有计分、掉落、暂停与重开流程保留。

### 清楚的通行规则

- **可通行：**道路、人行道、草地、铺装、停车位、地面标线、纸片与花草。低矮路缘作为路面边界，不阻挡移动。
- **不可穿过：**建筑、车辆、围栏、树池、喷泉、长椅、候车亭、油泵、垃圾箱、配电箱等有实体底座的物件。画面中的硬边、抬高底座、落地阴影与碰撞范围一致。
- **入口：**建筑仍封闭，木板、金属封条与角部警示可见；公园的围栏保留宽开口。地图边缘增加可见围栏，避免仅靠隐藏边界限制移动。
- 树冠覆盖角色或丧尸时自动变淡，脚下的树池继续保持实体。不会用树冠隐藏敌人，也不把树冠的整个投影都设成墙。
- 玩家、丧尸、Boss 落点、无人机巡逻、弹药碰撞、光线遮挡和声音遮挡共用场景障碍。普通子弹、电弧、火焰和两类导弹受阻挡；爆炸对遮挡后的对象不结算直线溅射。天气落雷仍按原规则从上方命中。

### 丧尸绕障与安全生成

- 普通丧尸、跳扑怪的接近阶段、冲锋怪的接近阶段和 Boss 均使用通向玩家的共享路径场；近处有直达路线时直接追踪。

- 每次生成检查两种通行余量的连通性；对孤立区域附近的装饰进行删减。道路主线、街区周边、停车前场和公园入口留出绕行空间。

- 普通敌人、开发者召唤、Boss、两种空投和无人机巡逻点避开实体设施；出生区域保持空旷。

## Boss 机制：蓄力跃击

| 阶段／参数 | 默认行为 |
| --- | --- |
| 接敌 | 与玩家距离小于 520 世界像素，冷却结束后发动 |
| 蓄力 | 1.3 秒，下蹲、扬尘、低吼，地面显示 120 像素半径的危险圈 |
| 锁定 | 前 0.9 秒跟随玩家位置，最后 0.4 秒锁定；红色圈由虚线变为实线并变亮，不显示文字 |
| 腾空 | 飞行 0.72 秒，最高抬升 112 像素；起跳后不会继续追踪玩家 |
| 砸地 | 伤害范围只结算一次，玩家受到 32 点伤害并被击退；周围落地丧尸只被推开，血量不变 |
| 反馈 | 冲击圈、裂纹、碎屑、尘土、低沉落地声和按距离衰减的震屏 |
| 恢复 | 落地硬直 0.8 秒，之后冷却 5.5–7.5 秒 |

可跑出标记或在落地瞬间翻滚／火箭跳来闪避。普通受击后的短暂保护不会抵消砸地，但翻滚与跳跃会同时免除该次伤害和击退。墙体阻挡冲击伤害与击退，推开角色时使用现有墙体碰撞，不穿墙。

当玩家靠近建筑或墙角，Boss 会选择附近能容纳自身的室外空地，预警圈始终显示实际落点。腾空期间不与地面角色挤压、地面弹药和火焰不命中 Boss；落地后恢复正常受击，蓄力期间可以击杀来中止攻击。自然落雷仍可命中腾空 Boss。

## V1.3.0 内容

- **武器命中反馈：**霰弹枪是厚重的多弹丸撞击，加特林是短促的连续穿透反馈，火箭／手雷是不同的低沉冲击；喷火器和燃烧瓶使用独立灼烧声。每类 3 个变体。弹丸记住发射它的武器，切枪不改变飞行中子弹的声音。
- **控制叠音：**同一帧内同类命中合并到最近的受击目标，并对连射、散弹和持续火焰分别限频，避免大量粒子把声音堆得太响。
- **重制喷火器：**阀门点火、低频燃烧、气流喷射和松开后的泄压收尾分开处理；持续喷射平滑循环，暂停、死亡和重新开局会清理声音。
- **更安静的雨声：**彻底移除原风声。相同用户音量下，雨声的平均信号电平比旧风声约低 8.5 dB；新用户默认环境音为 30%。既有音量设置继续保留。进入建筑后进一步降低雨声音量与高频。
- **可见降雨：**斜向雨丝、地面小水圈，建筑范围内不绘制雨丝；绘制数量有上限，暂停时天气冻结。
- **偶发雷电：**每隔 35–65 秒一次。全地图短暂增加柔和冷色环境光，约 0.48 秒内消退；雷声略晚于闪电，根据距离和室内外位置调整声音。闪电不覆盖 HUD。
- **随机落雷：**每次雷电有 15% 概率落地；坐标均匀随机分布于整个地图，不追踪玩家或丧尸。落雷有细闪电、落点光和短暂痕迹。
- **落雷伤害：**落点半径 42 世界像素与角色碰撞半径相交时，玩家受伤 35、丧尸受伤 120，每次仅结算一次。雷击不会因翻滚／短暂无敌而免伤，建筑不提供防雷。自然雷击及其引发的 Bloater 连锁击杀不增加玩家击杀数或分数；正常掉落仍保留。
- **64 段原创合成素材：**雨声、雷声和新增命中声均可离线使用，附 WAV 与可重新生成的脚本。

雷声与雨声由主菜单“环境音 / Ambience”滑块控制；枪声和命中声由“音效 / Effects”控制。

## 项目结构

- 桌面键盘鼠标操作；保留原单人模式和独立离线 HTML 入口。
- 联机客户端通过同源 `/ws` 连接服务器，每个房间运行独立工作线程。
- 共享战斗代码保证单人和合作的武器、敌人、碰撞规则保持一致；服务器使用无绘制的适配层。
- 依赖 `ws` 8.22.0 已随源码内置，许可证保留；Node.js 运行时需要开服者自行安装。
